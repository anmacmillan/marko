# Marko

A calm terminal Markdown editor.

## Ordinary editing

Use arrow keys and type normally. There are no modes.

> Markdown remains plain text and there is no preview pane.

## Table editing

Place the cursor in a cell and press Tab.
Press Ctrl-T on an empty line to create a new table.

| Feature | Behaviour |
| --- | --- |
| Tab | Move to the next cell |
| Enter | Add a new table row |
| Ctrl-S | Save ordinary Markdown |
